Цель
   Реализовать символьный драйвер контроллера GPIO для процессора Rockchip RK3588 и
   ОС Linux.


 Функциональные требования:
   1. Ф1. Драйвер должен обеспечивать возможность настройки направления передачи
   данных по интерфейсу GPIO
   2. Ф2. Драйвер должен обеспечивать возможность установки выводов GPIO в заданное
   значение.
   3. Ф3. Драйвер должен обеспечивать чтение текущего состояния входных выводов
   GPIO.
   4. Ф4. Взаимодействие с контроллером GPIO должно осуществляться с помощью
   символьного устройства.
   5. Ф5. Драйвер должен обеспечивать возможность использования всех имеющихся
   контроллеров GPIO.
   6. Ф6. Драйвер не должен позволять использовать один и тот же контроллер GPIO
   несколькими процессами.
